\subsection{Agent Distribution in Finite Horizon}
There are two ways to compute the agent distribution in finite horizon, simulation and iteration. The user must define/input the period-1 distribution. The iteration method is used by default as it has a better combination of speed and accuracy than simulation, but because the iteration requires more memory it will sometimes not be possible and simulation should then be used instead (default is \textit{vfoptions.iterate=1}, setting it to 0 means simulation will be used instead). When we use simulation we are essentially just doing a panel data simulation, but then converting the result into an agent distribution.

% Note that VFI Toolkit stores the finite agent distribution as a mass one probability distribution conditional on each age, as well as a vector of weights for ages.\footnote{Two motives. That every age-conditional distribution should be mass one is something we can check when trying to debug. I suspect this is more robust to numerical rounding error.}

\subsubsection{Simulating the Agent Distribution}
The pseudocode for simulating the agent distribution follows. Note everything is done based on the index of $(a,z)$, not the value. We use $\mu_j$ to denote the distribution at age/period $j$, and $g$ denotes policy function, $\pi_z$ denotes the transition matrix for the exogenous state.
\begin{algorithmic}
 \State Define initial age-1 distribution $\mu_1(a,z)$
 \State Define age-weights $\omega(j)$
 \State We will perform $N$ simulations of length $J$
 \For $i$ count from $1$ to $N$ (Parallel-for over cpu cores)
  \State Draw starting point $(a_1,z_1)$ from $\mu_1(a,z)$
  \State Create $Dist_i=zeros($\textit{size of $(a,z,j)$ space}$)$
  \For $j$ counts from $1$ to $J$
   \State Get $a_j=g(a_{j-1},z_{j-1},j-1)$
   \State Draw $z_j$ from $\pi_z(z_j|z_{j-1};j)$
   \State $Dist_i(a_j, z_j,j)=Dist_i(a_j, z_j,j)+1$ (recall, using indexes, not values)
  \EndFor
 \EndFor
 \State $Dist(:,:,:,i)=Dist_i$ \Comment Put the $Dist_i$ together
 \State $Dist=sum(Dist,$in the $i$ dimension$)$
 \Comment $Dist$ is now a count of how many times each point in distribution was visited during the simulations
 \State $Dist(:,:,j)=Dist(:,:,j)/sum(Dist(:,:,j))$, for each $j$
 \Comment Normalize conditional on age to be a probability distribution
 \State Multiply $\omega$ along the $j$ dimension of $Dist$.
 \\ \Return $Dist$
\end{algorithmic}

\subsubsection{Iterating the Agent Distribution}
To iterate the agent distribution in finite horizon we need an initial distribution defined by the user, $\mu_1$, and then construct the transition matrix on $(a,z)$ for each period $j$ denoted $P_j$. $P_j$ is constructed by combining the policy function for period $j$, $g_j$, with the transition matrix on exogenous shocks for period $j$, $\pi_{z,j}$.

We just iterate $j$ times,
\begin{algorithmic}
 \State Define initial age-1 distribution $\mu_1(a,z)$ (must be mass 1)
 \State Define age-weights $\omega(j)$
 \For $j$ counts from $1$ to $J-1$
  \State Construct $P_j$ from $g_j$ and $\pi_{z,j}$
  \State $\mu_{j+1}=P_j \mu_j$ \Comment Iterate agent distribution
 \EndFor
 \State Store all the $\mu_j$ in $\mu$
  \State Multiply $\omega$ along the $j$ dimension of $\mu$.
 \\ \Return $\mu$
 \end{algorithmic}
In the actual codes the storing of $\mu_j$ in $\mu$ is done inside the for-loop, and we just have a $\mu_{new}$ and $\mu_{old}$ rather than all of the $\mu_j$.

VFI Toolkit by default will actually use the Tan improvement when iterating on the agent distribution and we turn to that now. We note that $P$ here takes us directly from $(a,z)$ to $(a',z')$.

\subsubsection{Tan Improvement Iterating the Agent Distribution}
The Tan improvement is the observation that instead of using $P$ we can use $g$ and $\pi_z$ one-by-one. This bit of genius means we do exactly the same, but in a way that is faster and less memory demanding (people spent 30+ years using $P$ before Tan saw that you could split it in two!).

We just iterate $j$ times,
\begin{algorithmic}
 \State Define initial age-1 distribution $\mu_1(a,z)$ (must be mass 1)
 \State Define age-weights $\omega(j)$
 \For $j$ counts from $1$ to $J-1$
  \State Construct $\Gamma_j$ from $g_j$
  \State $\mu_{temp}=\Gamma_j \mu_j$ \Comment First step of Tan improvement
  \State $\mu_{j+1}=\pi_{z,j} \mu_{temp}$ \Comment Second step of Tan improvement
 \EndFor
 \State Store all the $\mu_j$ in $\mu$
  \State Multiply $\omega$ along the $j$ dimension of $\mu$.
 \\ \Return $\mu$
 \end{algorithmic}
There is some reshaping of matrices involved in the Tan improvement that I have glossed over here, for a full explanation see \cite{Tan2020}.

The Tan improvement can be understood as breaking the move from $(a,z)$ to $(a',z')$ into two steps. The first step is from $(a,z)$ to $(a',z)$, and the second step is from $(a',z)$ to $(a',z')$.

\subsubsection{Tan Improvement with Semi-Exogenous shocks}
Semi-exogenous shocks are exogenous states for which the transition probabilities depend on a decision variable (see Life-Cycle Model 30 for an example). So $\pi_{semiz}(semiz'|semiz,d)$ gives the probability of next-period semi-exogenous state based on the current semi-exogenous state and on the decision variable.

Using the Tan improvement requires a minor modification. Note that we cannot treat $semiz$ like we treat $z$, in the second step of the Tan improvement, because semiz depends on $d$ (and hence on $a$ and $z$). Instead we have to include $semiz$ in the first step of the Tan improvement.

We just iterate $j$ times,
\begin{algorithmic}
 \State Define initial age-1 distribution $\mu_1(a,semiz,z)$ (must be mass 1)
 \State Define age-weights $\omega(j)$
 \For $j$ counts from $1$ to $J-1$
  \State Construct $\Gamma_j$ from $g_j$ and $\pi_{semiz,j}$
  \State $\mu_{temp}=\Gamma_j \mu_j$ \Comment First step of Tan improvement
  \State $\mu_{j+1}=\pi_{z,j} \mu_{temp}$ \Comment Second step of Tan improvement
 \EndFor
 \State Store all the $\mu_j$ in $\mu$
  \State Multiply $\omega$ along the $j$ dimension of $\mu$.
 \\ \Return $\mu$
 \end{algorithmic}
The difference from the standard Tan improvement is all in the first step, which now includes the semi-exogenous state transitions alongside the standard endogenous state transitions.
There is some reshaping of matrices involved in the Tan improvement that I have glossed over here, for a full explanation see \cite{Tan2020}. Note that now our distribution is on $(a,semiz,z)$, and $\Gamma_j$ is used in the first step to change to $(a',semiz',z)$, and then the second step goes to $(a',semiz',z')$.\footnote{Getting the Tan improvement to work here does require the order $(a,semiz,z)$, in fact the whole toolkit got rewritten just to be able to do this as it originally had $z$ then $semiz$.}

\subsubsection{Iterating the Agent Distribution with 'nProbs'}
Sometimes our policy for the next-period endogenous state does not sit on a single grid point. It might be 'between' two grid points (e.g., experienceasset, \href{https://github.com/robertdkirkby/GridInterpolationLayer}{grid interpolation layer}, or residualasset), or it might send us to several grid points at once (e.g., riskyasset or experienceassetu, where each value of an i.i.d. shock $u$ leads to a different between-grid-points value). VFI Toolkit handles all of these with a single unified approach called 'nProbs'.

The idea of nProbs is that we represent the policy for the next-period endogenous state as $N\_{}probs$ next-period grid points together with $N\_{}probs$ probabilities. The probabilities sum to one, because the agent goes somewhere next period with certainty. Once we have the $N\_{}probs$ grid points and their probabilities, the rest of the agent distribution iteration is unchanged. Several familiar cases are just particular values of $N\_{}probs$:
\begin{itemize}
\item A standard on-grid policy is $N\_{}probs=1$: a single next-period grid point with probability one. [Just pointing out the relation, these do not use the $nProbs$ codes, just the standard codes.]
\item A 'between two grid points' policy is $N\_{}probs=2$: the lower and upper grid points, with two probabilities. This covers experienceasset, grid interpolation layer, and residualasset.
\item A policy driven by an i.i.d. shock is $N\_{}probs=2*n\_{}u$ (this is what was previously called 'uProbs'): for each of the $n\_{}u$ values of $u$ we get a between-grid-points policy, i.e. a lower and upper grid point. This covers riskyasset and experienceassetu.
\end{itemize}
More elaborate combinations simply give larger $N\_{}probs$; for example a standard endogenous state that is done with grid interpolation layer used together with a riskyasset gives $N\_{}probs=2*n\_{}u*2$ (lower/upper for the riskyasset, for each $u$, crossed with lower/upper for the standard asset with grid interpolation layer).

We store the policy as the $N\_{}probs$ next-period grid point indices $Policy_{l}(a,z,\cdot,j)$ and the corresponding probabilities $Policy_{\pi}(a,z,\cdot,j)$, where the extra dimension has length $N\_{}probs$ and the probabilities sum to one over that dimension.

\paragraph{Getting the grid points and probabilities: the between-grid-points case.}
Consider a single between-grid-points policy value $a*$ (we will have one for each point in the state space, so we do this many times; here just consider one). Our grid of values on the endogenous state is $a\_{}grid=\{a_1,a_2,\dots, a_{n\_{}a}\}$. We first find the lower grid point, the grid point immediately below $a*$, by solving $\argmax_{i=1,\dots,n\_{}a} \{a_i\leq a*\}$; call it $a_{i_l}$. By definition the upper grid point is one above, $a_{i_l+1}$. The probability of the lower grid point is $\pi_{l}=1-\frac{a*-a_{i_l}}{a_{i_l+1}-a_{i_l}}$; this is linear interpolation, so if $a*$ is one-quarter of the way from the lower to the upper grid point then the lower grid point gets probability three-quarters, and if it is halfway it gets one-half. The upper grid point probability is $1-\pi_{l}$. This is the $N\_{}probs=2$ case: two grid points $(a_{i_l},a_{i_l+1})$ with probabilities $(\pi_{l},1-\pi_{l})$.

experienceasset and residualasset produce the policy as such an $a*$ value directly. For grid interpolation layer the $Policy$ instead already stores the lower grid point on $a\_{}grid$ (so we have the lower grid point directly) together with the 'interpolation-layer index', which is $n2$ points evenly spaced between two consecutive grid points of $a\_{}grid$ (the index runs from $1$ to $n2+2$, as it includes the two endpoints). Since these interpolation-layer points are evenly spaced, the lower grid point probability is simply $\pi_l=1-($interpolation-layer-index$-1)/(n2+1)$. Either way we end up with the same two grid points and two probabilities.\footnote{The use of 'nProbs' does not depend on linear interpolation. In VFI Toolkit it is (currently) always linear interpolation that is used to set the probabilities, but in principle any other scheme could be used.}

\paragraph{Getting the grid points and probabilities: the i.i.d.-shock case.}
For riskyasset and experienceassetu, each of the $n\_{}u$ values of the i.i.d. shock $u$ gives a different between-grid-points value. We apply the between-grid-points construction above to each of the $n\_{}u$ values, giving $2*n\_{}u$ grid points. The probability attached to each of these grid points is the interpolation weight ($\pi_l$ or $1-\pi_l$ for that $u$) multiplied by the probability of that value of $u$ (from $\pi_u$). So again we have $N\_{}probs$ grid points with $N\_{}probs$ probabilities that sum to one, just now with $N\_{}probs=2*n\_{}u$.

\paragraph{Constructing the transition and iterating.}
Once the policy is in the form of $N\_{}probs$ grid points and probabilities, constructing the transition is a small change from the on-grid case. First consider the simpler setting with no markov $z$, just an endogenous state $a$. With an on-grid policy, the transition matrix $P_j$ from $(a)$ to $(a')$ had a single $1$ in each row. With an nProbs policy, each row instead has $N\_{}probs$ non-zeros, in the columns of the $N\_{}probs$ next-period grid points, with values equal to their $N\_{}probs$ probabilities. Putting the markov $z$ back in, the on-grid $P_j$ had $n\_{}z$ non-zeros per row (the single $a'$ crossed with the $n\_{}z$ next-period $z'$, with probabilities from $\pi_z$), while the nProbs $P_j$ has $N\_{}probs*n\_{}z$ non-zeros per row, with probabilities given by $\pi_z(z_c,:)$ crossed with the $N\_{}probs$ policy probabilities.

Once we have $P_j$ for $j=1,\dots,J-1$, the rest of the agent distribution algorithm is exactly as before; the iteration
\begin{algorithmic}
 \State Define initial age-1 distribution $\mu_1(a,z)$ (must be mass 1)
 \State Define age-weights $\omega(j)$
 \For $j$ counts from $1$ to $J-1$
  \State Construct $P_j$ from $g_j$ (now as $N\_{}probs$ grid points and probabilities) and $\pi_{z,j}$
  \State $\mu_{j+1}=P_j \mu_j$ \Comment Iterate agent distribution
 \EndFor
 \State Store all the $\mu_j$ in $\mu$
  \State Multiply $\omega$ along the $j$ dimension of $\mu$.
 \\ \Return $\mu$
 \end{algorithmic}
is unchanged except that $P_j$ now has more non-zeros.\footnote{Only the non-zeros matter in practice as you will always want to implement this using sparse matrices.} In practice VFI Toolkit does not build $P_j$ directly: it uses the Tan improvement, constructing $\Gamma_j$ from the $N\_{}probs$ grid points and probabilities (as a sparse matrix, letting repeated indices accumulate) for the first step, and then applying $\pi_{z,j}$ for the second step, exactly as in the on-grid Tan improvement described earlier. This is how \texttt{StationaryDist\_{}FHorz\_{}Iteration\_{}nProbs\_{}raw.m} is organized.
